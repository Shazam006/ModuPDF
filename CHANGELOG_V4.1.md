# ModuPDF V4.1

- Consolidação do organizador multi-PDF.
- Permite duplicar páginas.
- Permite usar a mesma página de origem mais de uma vez no PDF final.
- Endpoint `/api/system/capabilities` para detectar LibreOffice, Tesseract, OCRmyPDF, Ghostscript e VeraPDF.
- Mantém processamento local.
- Escopo explicitamente exclui IA, PDF→WebP, PDF→Markdown e automação/workflows.
