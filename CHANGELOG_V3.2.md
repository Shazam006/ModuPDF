# ModuPDF V3.2

## Organizador multi-PDF

- Carregamento múltiplo de PDFs.
- Barra lateral com todos os PDFs carregados.
- Contagem de páginas por documento.
- Remoção de documento inteiro.
- Visualização da origem de cada página.
- Reordenação de páginas entre PDFs diferentes.
- Exclusão e rotação de páginas selecionadas.
- Endpoint `/api/organize-multi` para gerar o PDF final.
